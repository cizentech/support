## Version and compatibility

Release versions, dates, file sizes and checksums are not published in the current source. Check the downloaded package documentation and contact [technical support](Technical_Support.md) if the required version or compatibility is unclear. A package filename is not a complete compatibility statement.

Downloads are hosted externally on SharePoint. If a link requires access or fails, send the guide name and package name to support. Do not send credentials.
