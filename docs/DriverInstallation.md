# Driver Installation

Check the model label before selecting a package. See [Downloads](Downloads.md) for the available package names and platform labels.

> Package names below identify Windows 10 x64 (S2) and Windows 11 x64 (S6). Compatibility with other operating systems or board revisions must be confirmed with support.

## Before installation

1. Record your board model, hardware revision and Windows version/architecture.
2. Install the required Visual C++ runtime, then follow the instructions for your model.
3. Check Device Manager for the board and any warning symbols after installation.
4. Open [CameraMaster](CameraMaster.md) and check the grabber connection status.

If installation fails, record the Device Manager error code and follow [Troubleshooting](Troubleshooting.md).
